# Agent Workspace designs and open proposals

The implemented Agent Workspace contracts live under [architecture](../../docs/architecture/agent-workspace.md), [Agent Skills](../../docs/architecture/agent-skills.md), [LLM Services](../../docs/architecture/llm-services.md), [deployment](../../docs/agent-workspace-deployment.md) and [E2E tests](../../docs/e2e-test-cases/README.md).

This directory holds **open proposals and living PoC designs under review**, including designs implemented on separate feature branches but not yet merged into `next`. User-facing rules for when an agent should ask permission belong in the bundled [`mgd` core skill](../../../packages/mgd/skills/SKILL.md). The already-implemented DSH Agent Skill publication/delete/force-sync approval behaviour belongs in [the Skill architecture](../../docs/architecture/agent-skills.md#one-approval-for-publishing) and [ADR 0008](../../docs/adrs/0008-model-mediated-agent-skill-publication-approval.md). No generic non-bypassable mutation approval design is committed here. A document's presence here alone does not establish implementation, security qualification or release; read its status and branch scope. Accepted decisions should be captured in [ADRs](../../docs/adrs/); once integrated into `next`, reconcile the maintained architecture and tests, then remove or archive the superseded proposal.

- [LLM access profiles and soft usage limits](./llm-access-profiles.md) — implemented PoC under #3937 for #3838, with reconciliation under review in [PR #3973](https://github.com/magda-io/magda/pull/3973); not merged into `next` or production-qualified.
- [LLM access profiles: Settings UI](./llm-access-profiles-ui.md) — living design for the implemented PoC's Access Profiles, My Usage and User Usage screens; browser/accessibility qualification is separate.
- [Observability and audit](./observability.md) — deferred design, not an implemented service-level contract.
- [GKE security qualification](https://github.com/magda-io/magda/issues/3848) — tracked in public engineering work and the [focused provider E2E](../../docs/e2e-test-cases/agent-workspace-gke-security.md), not a separate duplicative proposal document.
